HomeLife v1.1.2 deployment visibility fix

Purpose:
- Keeps files at ZIP root for direct unzip into the homelife project root.
- Adds a safe visible fallback in index.html so the page does not stay stuck on Loading HomeLife if GitHub Pages is serving source files instead of the built Vite output.
- Keeps the React app intact for normal Vite/GitHub Actions deployment.
- Keeps Supabase environment variables in the GitHub Pages workflow.

Important deployment note:
- Preferred: GitHub Settings > Pages > Source = GitHub Actions.
- If using branch deploy instead, use main / docs after building and committing the docs folder.

After unzipping:
1. npm run build
2. git add .
3. git commit -m "Fix HomeLife deployment visibility v1.1.2"
4. git push
5. Confirm GitHub Actions deploy finished successfully.
