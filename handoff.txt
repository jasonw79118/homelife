HomeLife v1.1.3 root deploy fix

What was fixed:
1. Rebuilt the app and copied the production output to /docs.
2. Changed GitHub Actions to deploy the prebuilt /docs folder directly, avoiding the npm runner failure: "Exit handler never called!"
3. Added a cross-platform script: npm run build:docs.
4. Added .nojekyll and 404.html to /docs for GitHub Pages.
5. Hardened app startup so old/bad localStorage data should not leave the site stuck on "Loading HomeLife...".
6. Added deeper data normalization for users, accounts, transactions, budget categories, debts, shopping lists, price catalog, and statement imports.
7. Added a React error boundary with a button to clear saved demo data if a browser has bad older localStorage.
8. Files are packaged at ZIP root. Unzip directly into C:\Users\jason\homelife and overwrite.

After unzipping:
1. git add .
2. git commit -m "Fix HomeLife deploy v1.1.3"
3. git push
4. GitHub repo > Settings > Pages > Source should be GitHub Actions.

Do not run npm install in GitHub Actions for this version. The workflow deploys /docs directly.

For future code changes:
1. npm install
2. npm run dev
3. npm run build:docs
4. git add .
5. git commit -m "Update HomeLife"
6. git push
