HomeLife starter update
Version: 1.1.0

Added:
- Local Price Catalog page for Walmart/Sam's/other price estimates.
- Shopping list Add Item now checks the price catalog and pulls estimated price, store, category, and notes.
- Bank Statement Import page for CSV files.
- Statement import is designed to parse locally in the browser and store sanitized rows only.
- Reconciliation status: matched, possible, or missing from register.
- Finance privacy: Register, Budget, Debt, and Statement Import are hidden from household_member and child demo roles.
- .env.example added for Supabase setup.

Important:
- This ZIP is packaged with files at the root level, not inside an extra homelife/ folder.
- Walmart live price lookup should be added through an approved API or Supabase Edge Function later. Do not scrape Walmart pages directly from GitHub Pages.
- Front-end hiding is in place now, but real protection requires Supabase Auth plus Row Level Security before storing sensitive financial data online.
