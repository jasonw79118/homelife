HomeLife update - Meal Planner, Pantry, and Delete Coverage
Version: 2026.06.12.0005

What changed
1. Added Pantry Builder
   - Tracks dry goods, spices, canned goods, frozen foods, meats, sauces, vegetables, fruits, baking goods, dairy, snacks, drinks, household, and other items.
   - Captures quantity, unit, location, estimated unit value, expiration date, notes, store, and price catalog link.
   - Includes search, category filter, quantity adjustment, CSV export, and delete buttons.

2. Added Meal Planner
   - Adds meals by date, meal type, servings, notes, and ingredients.
   - Each ingredient can be marked as pantry-covered if already accounted for.
   - Each meal shows total food value, pantry-covered value, and new grocery cost.
   - Adds missing ingredients directly to a selected/new grocery list.
   - Includes add/delete meal and add/delete ingredient controls.

3. Shopping List improvements
   - Add Shopping List now has Delete List.
   - Add Item now has Delete Item.
   - Meal Planner items are added with source notes so the list shows which meal created the item.

4. Delete button coverage
   - Added delete controls to price catalog, shopping lists, shopping items, pantry items, meal plans, meal ingredients, statement import rows, transactions, budget categories, and debts.
   - Statement import still has Clear Imported Rows for full cleanup.

5. Dashboard updates
   - Added meal plan grocery cost, pantry estimate, and food value summaries.

6. Data model update
   - Added pantryItems and mealPlans to AppData.
   - normalizeData migrates old saved HomeLife data by adding missing pantry and meal fields without breaking existing register, budget, shopping, price catalog, or statement import data.

Deploy notes
- Project uses Vite/React/TypeScript.
- GitHub Pages base is /homelife/.
- deploy.yml uses Node 20, pins npm 10.9.2, forces the public npm registry, retries npm install after a cache clear, builds Vite, copies the SPA fallback, and deploys a uniquely named homelife-pages artifact.

Important
- This is still browser-local storage. Export JSON Backup from Settings before major changes.
- The meal cost logic treats pantry-covered ingredients as already accounted for and only adds non-pantry-covered ingredients to the grocery list.


Packaging correction
- This ZIP is rooted at the project files. Unzipping it into the repository root should place package.json, index.html, src/, and .github/ directly at the root with no extra parent folder.

Deployment correction
- The prior Pages failure was caused by more than one artifact named github-pages in the same workflow run. This workflow uploads a uniquely named artifact, homelife-pages, and tells actions/deploy-pages@v5 to deploy that artifact_name.
- The npm install step now pins npm to 10.9.2 and retries after npm cache clean to avoid npm's intermittent Exit handler never called failure.
- If older workflow files remain in the repository, remove or disable them so only this .github/workflows/deploy.yml runs for HomeLife.
