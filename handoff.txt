HomeLife v1.1.4 Root Deploy Fix

Problem observed:
The live GitHub Pages site displayed the fallback message: "Deployment check..." instead of the HomeLife app.

Root cause:
The browser was receiving an HTML fallback/shell instead of a reliable built application. Prior workflows also depended on npm install/build in GitHub Actions, which had already failed with npm runner errors.

Fix:
This patch ships HomeLife as a self-contained static app in both root index.html and docs/index.html.

Deployment options:
1. Preferred: GitHub Pages Source = GitHub Actions. The included workflow deploys docs directly and does not use npm.
2. Alternate: GitHub Pages Source = Deploy from a branch, main / docs.
3. Root deploy also works because root index.html is also the app.

Next recommended patch:
Add real Supabase authentication and row-level security after the public site is consistently visible.
