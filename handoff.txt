HomeLife v1.2.0 handoff

Purpose:
- Adds starter grocery price projection catalog for Canyon, TX / ZIP 79015.
- Walmart store context: Walmart Supercenter #793, 1701 N 23rd St, Canyon, TX 79015.
- United store context: United Supermarkets N 23rd & Russell Long, 201 N 23rd St, Canyon, TX 79015.

Deployment:
- Static GitHub Pages deployment remains in docs/.
- .github/workflows/deploy.yml deploys docs directly; no npm install or Vite build is required.
- Root index.html mirrors docs/index.html for branch-root testing.

Price catalog features:
- 86 starter estimate rows across Walmart and United Supermarkets.
- Search/filter by store and category.
- CSV export/import.
- Load/Refresh 79015 Catalog button merges default catalog into local browser data.
- Online lookup links are provided, but the app does not scrape Walmart or United.

Privacy:
- Statement CSV import still parses locally in-browser and stores only sanitized rows.
- Finance pages remain hidden for household/child profiles.

Known limitation:
- Prices are starter estimates, not live checkout prices. Live Walmart pricing should use approved Walmart APIs through a backend/Supabase Edge Function. United pricing should be manually verified or imported from user-maintained data because no official public product-pricing API was identified.
